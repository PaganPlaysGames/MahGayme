# MahGayme (MapleStory-Inspired Prototype)

A lightweight Godot 4 side-scrolling action prototype inspired by MapleStory.

## Features
- Side-scrolling 2D training field.
- Move + jump controls.
- Short melee slash attack.
- Slimes that patrol and can be defeated.
- Quest UI tracking slime defeats (0/5).

## Controls
- **Left / Right**: Move
- **Up**: Jump
- **Enter**: Slash attack

## Run
1. Open the project in Godot 4.6+.
2. Press **Play** (F5).
